# 卫戍协议 · 规则手册

> 全部来自老大 2026-11-10 ~ 11-11 的实战纠正。
> 按「一局的时间顺序」组织：开局 → 每回合 → 布阵 → 操作 → 判读。
> **打之前从头读一遍，比什么都强。**

---

# 一、开局（选模式/盟约/策略）

## 1.1 模式
- 单人：**个人模拟** → 独立模拟 → 选规程等级 → 开始模拟
- 恢复进行中的局：卫戍协议模式页右下 **「断线重连」(1185,672)**
  - ❌ 不要点「个人模拟」（没反应）
  - ❌ 不要点「放弃模拟」（会结算掉这局）

## 1.2 盟约（1/3 步，有倒计时）
- 核心盟约选 1 个，附加盟约选 5~6 个
- 没选的盟约本局不会出现
- 通用思路：**来什么玩什么**，别开局锁死某个大盟约（方差太大）

## 1.3 策略（2/3 步，有倒计时）
- **策略列表可以下滑！必须滑到底看完再选，不要顺手点第一个**
- 优先级：
  1. 有「砍诺特」→ 优先（唯一可以留钱的策略）
  2. 没有 → 选能配合经济/叠层的（昆图斯、大嘴莫布、复奏类）
- 看清「初始生命值」和效果再确认

## 1.4 编队（3/3 步）
- 自选编队可以空着直接准备就绪

# 二、每回合开始（固定四步，顺序不能乱）

```
① 读金币
② 看商店刷新了什么（卡名 → 查资料库定职业/位置）
③ 看下一波敌人是什么类型（顶部放大镜 930,35）
④ 看商店升级费用降到多少了
```

## 2.1 金币
- 位置：右下角 (1140,490)-(1260,550)
- **钱不跨回合，回合结束清零**

## 2.2 商店
- 点卡片读面板 → 查 `卫戍协议-数据.json` 的【位置】字段（近战/远程）
- **不许用阻挡数猜职业**（慕斯看着像远程，实际是近卫/近战）

## 2.3 敌人
- 点顶部放大镜 **(930,35)** → 右侧弹出「敌人」面板（名字 + 特性）
- **判断走哪个门：敌人靠下 = 下门(a9)出，靠上 = 上门(d9)出**
- 敌人面板可以读到：普通囚犯 / 老练囚犯 / 重犯 / 雪怪小队 / 深池逐火战士 / 萨卡兹刀兵…

## 2.4 商店升级（重要）
- 升级费用**每回合 -1**
- **降到 0 时立刻升级（免费）**，否则永远刷不出高等级卡
- 操作：点「升级」→ 还会弹「确认升级」→ 再点一次
- 不影响阵容的前提下，能升就升

# 三、经济（花钱）

## 3.1 钱必须花完
- **除了「砍诺特」策略可以留钱，其他策略本回合必须把钱花光**
- 准备就绪前看一眼金币，非 0 就继续买（干员 / 装备 / 刷新 / 升级）

## 3.2 优先买什么
| 类别 | 代表干员 | 为什么 |
|---|---|---|
| 经济卡 | 至简、真理（**购买价 1**）、忍冬、奥斯塔（免费刷新） | 便宜、滚雪球 |
| 通用叠层卡 | 魔王(6阶+10)、空弦、霍尔海雅、云迹、瑕光、夜莺、夏栎 | 不点名盟约，玩啥都能叠 |
| 同名三连 | 3 个同名 → 自动升 2 阶 + 开免费三选一商店 | 质变 |

## 3.3 金币来源
- 每回合金币固定发放
- 「远见」盟约是经济引擎（寒檀 +3/回合）
- 战术决策里的「财富」给 1 资金

# 四、布阵（最重要的一章）

## 4.1 基本阵型（老大原话）

```
敌人来的方向 ←  盾位 → 战士 → 输出 → 奶  →  自己蓝门
```

- **盾位（重装）最前**：血厚防高，负责挡
- **战士（近卫）紧跟其后**：补输出、也扛一点
- **输出（狙击/术师）再往后**：安全位置打
- **奶（医疗）最后**：奶前面所有人
- **近战推荐放 d 行**（敌人汇合的主路）

d 行具体排法（从靠红门的右侧往左）：
```
d7 盾位  →  d6 战士  →  d5 输出  →  d4 输出/奶  →  d3 奶
```

## 4.2 必须检查：输出的攻击范围够不够得到前排
放输出的时候一定看它的范围能不能罩住盾/战士所在那一格。
**罩不到 = 前排白挡、输出白站。** 今天犯过：陨星放 c6、摆渡人放 a7，两者隔太远，各打各的。

## 4.3 远程不能放敌人必经之路
没有近战保护会被贴脸秒杀。
- **敌路**：a7 a8 b7 c7 c8 + 整个 d 行
- **安全位**：围墙 b2 b6 c2 c5 c6 d2；偏左地面 a2 a3 b3 c3
- 例外：远程可以放在**近战后面**（有近战挡着就安全）

## 4.4 按攻击范围决定前后
| 干员 | 范围 | 该放哪 |
|---|---|---|
| 狙击（陨星） | 很大，覆盖好几格 | **往后放一排**，让范围覆盖整段路磨血 |
| 术师 | 中等 | 中排 |
| 近战/重装 | 只打面前一格 | **最前排**压路 |

## 4.5 站位要灵活
每次放之前看三样：
1. 这波敌人什么类型（近战/远程/火伤/元素）
2. 敌人从哪来、往哪走
3. 干员攻击范围够不够到最空的那段路

## 4.6 朝向
- **朝向 = 朝向敌人来的方向**（本图朝右）
- 不能随机，要按敌人进攻方向 + 队友站位决定
- 放置后划 **400px / 1200ms** 才生效（短了不生效）

# 五、地块（本图 AC-SP-2）

## 5.1 可放置格（19 个）

**地面 13 个（能阻挡）**
```
a2 a3 a7 a8   /   b3 b7   /   c3 c7   /   d3 d4 d5 d6 d7
```

**围墙 6 个（能放但不阻挡）**
```
b2  b6  c2  c5  c6  d2
```

## 5.2 围墙特性
1. 能放人（不是不能放）
2. **近战敌人打不到里面的人**（安全位）
3. **里面的人不阻挡敌人**
4. 但**不免疫远程攻击和特殊群体攻击（AOE）**

## 5.3 不可放置
- 除上面 19 格，其余格子放不了（拖过去会失败）
- 阻隔工事占据的格子也不能放

## 5.4 棋盘是透视梯形
- 下大上小，**每排格子大小不同**，同一排内相同
- 列距：d 行 76px、c/b 行 80.75px、a 行 86px
- 行 y：d=228~236、c=286~300、b=361~367、a=448~450
- 坐标存在 `九格网格-ACSP2.json`（含像素 + 千分制两套）

# 六、地图结构（AC-SP-2）

```
d 行：d1 ... d7 d8 [d9 红门]    ← 上红门
c 行：       c3       c7
b 行：       b3       b7
a 行：[蓝门] a1 ... a7 a8 [a9 红门]   ← 下红门
```

## 6.1 两个红门都会出兵
- **d9（右上）** 和 **a9（右下）** 都是敌人出口
- 判断这一波走哪个门：**敌人靠下 = 下门，靠上 = 上门**

## 6.2 下路是斜着走的
```
下红门(a9) → a8 → a7 → …… → d 行
           → b8 → b7 → c7 → d 行
           → c8 → c7 → d 行
```
**下路的怪最后都会爬到 d 行**，所以 d 行是汇合点、也是最该重兵把守的地方。

## 6.3 蓝门在左侧（a1/a2 一带），怪进蓝门就掉血

# 七、操作手法

## 7.1 放干员（强制顺序）
```
① 先收起商店（右侧「收起」按钮约 1191,674）
   —— 商店展开时会盖住棋盘，落点全错
② 按住整备区的干员卡（从卡片中心偏左一点按下）
③ 拖到目标格松手
④ 从格子上往朝向划 400px / 1200ms
⑤ 点目标格核对面板名字，确认放对了
```

## 7.2 撤退
```
点场上干员 → 面板 → 点撤退按钮 (542,389) → 剩余可放置 +1
```

## 7.3 严禁
- ❌ **按返回键（keyevent 4）** —— 会直接退出游戏
- ❌ 商店展开状态下拖人
- ❌ 不核对就认为放好了

## 7.4 面板关闭
- 点棋盘空白处（如 1150,400），**不要点返回键**

# 八、战术决策（三选一）

优先级：
1. **保命类**（自愈：我方单位每次受伤回复 50 血）—— 干员活不下来时首选
2. **白送干员**（乌萨斯/伊比利亚驰援）—— 有空格时
3. **免费刷新**（补给：接下来 2 次刷新免费）—— 空格满时
4. **钱**（财富：+1 资金）

- 选定后**无法更改**
- 装备补给里：卡西米尔竞技旗（部署后 15 秒内伤害 135%）适合快速击杀

# 十、今天犯过的错（别再犯）

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 商店展开时拖人 | 落点全错 | 先收起商店 |
| 狙击放最前排 | 只能打一下，范围优势全废 | 往后放一排 |
| 狙击放敌路上 | 贴脸被秒 | 放围墙或偏左地面 |
| 远程和近战隔太远 | 射程够不到，各打各的 | 范围必须覆盖前排 |
| 只在 d 行布防 | 下路 a 行空了 | 两路都要看 |
| 钱没花完 | 回合结束清零 | 准备就绪前花光 |
| 商店升级拖到第 7 回合 | 前 6 回合全是 1 阶卡 | 费用到 0 就升 |
| 策略不滑就选第一个 | 错过好策略 | 滑到底看完 |
| 按返回键 | 游戏退出 | 点空白关面板 |
| 用阻挡数猜职业 | 慕斯近战当远程放围墙 | 查资料库 |
