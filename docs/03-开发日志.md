# 开发日志

## 2026-11-11 · 从零摸到能跑一局

### 走了哪些弯路

**1. 网格坐标一直算错**
一开始假设格子是均匀正方形，用固定列距推 → 全错。
后来发现是**透视梯形**（下大上小、每排列距不同），
而且**同一排的左右两端 y 还略有倾斜**（不是水平线）。

**2. 可放置格识别失败**
用「青绿色」过滤高亮像素，一直提取不到。
根因：**高亮是黄绿色 rgb≈(120,170,50)，蓝色通道很低**，
按 b>110 过滤全漏了。改成 `g>130 && g-b>60 && g-r>20` 立刻可用。

**3. 拖拽放不上去**
`input motionevent` 多条拼接不生效（命令行之间有间隔，游戏读不到连续拖动）。
必须用**单条 `input swipe`**。

**4. 朝向滑动失败**
距离 120px 太短、220px 还是短，最后用 **400px / 1200ms** 才稳定。

**5. 按返回键退出游戏**
`input keyevent 4` 在明日方舟里会**直接退出到模拟器桌面**，不是关面板。
关面板要点棋盘空白处。

**6. 商店展开时放人 → 落点全错**
商店界面会盖住棋盘下半部分，拖动的落点落在商店上。
**必须先收起商店**。

**7. 远程放敌路上 → 秒死**
狙击放在 c7（敌人必经之路）没有近战保护，敌人一走过来就贴脸打死。

**8. 远程和近战隔太远 → 互相帮不上**
陨星放 c6、摆渡人放 a7，两个相隔太远，狙击的攻击范围够不到近战挡怪的位置。

### 关键突破

- **用游戏自己的高亮格当坐标真值**：按住干员时游戏会画出所有可放置格，
  这些位置是像素级精确的，比任何推算都准
- **千分制坐标**：`像素 = permille / 1000 × 屏幕宽高`，换分辨率不用重算
- **血量是唯一可靠的成功判据**：放完人打一回合，看血量掉不掉

### 实测数据

- 最好成绩：**通过 9 回合**（规程等级 2，个人模拟）
- 前 5 回合零掉血（d 行铺满近战 + c 行远程）
- 第 6 回合撞「深池逐火战士 + 燃损伤」火伤穿透才崩
- 截图时延：`adb screencap` raw ≈ 324ms（3~4 FPS），
  单帧高亮检测只要 6ms（瓶颈在传输不在算力）
