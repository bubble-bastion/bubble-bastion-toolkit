# 零、关卡结构与目标

```
第 1~13 回合：普通关（逐波变强，第 12~13 波最难）
第 14 回合：BOSS 关
还有概率出现「隐藏 BOSS 关」（条件未知）
```

| 档次 | 标准 |
|---|---|
| 及格 | 打完 13 回合 |
| 满分 | 13 回合 + 过 BOSS |
| 隐藏 | 触发隐藏 BOSS 并通关 |

**注意**：成绩显示「通过回合 13」= 普通关全通，不是死在 13。
2026-11-12 第 3 局达成（13 回合 + 打到 BOSS 波）。

# 一、开局（选模式/盟约/策略）

## 1.1 模式
- 单人：**个人模拟** → 独立模拟 → 规程等级 2 → 开始模拟
- 恢复进行中的局：模式页右下 **「断线重连」(1185,672)**
  - ❌ 点「个人模拟」没反应
  - ❌ 点「放弃模拟」会结算掉这局
- 若误入「编队页」（只有 选配助战/自选编队，没有继续按钮）：
  - 点左上角返回箭头 **(35,50)** → 回到模式页重新进

## 1.2 盟约（1/3 步，有倒计时）★ 关键修正

**盟约需要 3 人才能激活**（聚合需 2 人）。场上只有 8~10 个位置：

| 盟约数 | 占位 | 可行性 |
|---|---|---|
| 1 个 | 3 人 | ✅ 稳 |
| 2 个 | 6 人 | ✅ 推荐 |
| 3 个 | 9 人 | ⚠ 挤掉盾/奶 |
| 5~6 个 | 15~18 人 | ❌ 根本凑不齐，白选 |

**正确做法**：
```
核心盟约 1 个（凑 3 人）
附加盟约 1~2 个（各凑 3 人）
剩下位置留给盾/奶/克制位
```

**选之前先问：这套能不能凑够 3 人？凑不齐就别选。**

## 1.3 策略（2/3 步，有倒计时）
- **列表可以下滑，必须看完再选**
- 有「砍诺特」优先（唯一可以留钱的）；没有就选经济/叠层类
- 看清初始生命值

## 1.4 编队（3/3 步）
- 自选编队空着，直接 **准备就绪**

# 二、每回合开始（固定四步）

```
① 读金币（右下 1140-1260, 490-550）
② 读商店四格：x=520 是装备，x=681/842/1005 是干员
③ 读下一波敌人（顶部放大镜 930,35）
④ 看商店升级费用
```

## 2.1 商店必须升级 ★

**高阶干员只在高等级商店出现**：141 个干员里 4 阶以上有 72 个（黑键、艾雅法拉、赫拉格、温蒂…），
但只有把商店升到 3~4 级才刷得出来。

| 商店等级 | 大致卡池 |
|---|---|
| 1~2 级 | 1~2 阶 |
| 3~4 级 | 3~4 阶开始出现 |
| 5~6 级 | 5~6 阶 |

**升级费用每回合 -1，费用归零时实测免费** → 点「升级」→ 还会弹「确认升级」→ 再点一次。
升级成功后 `LEVEL` 位置会左移（x≈362 → x≈201），可以靠这个确认。

## 2.2 钱的优先级 ★

```
① 凑精锐（3 合 1）—— 见效最快
② 升商店 —— 打开高阶卡池
③ 才买零散低阶卡
```

**钱不跨回合，准备就绪前必须花光**（除「砍诺特」策略可留）。
花不出去时：升商店 > 刷新 > 买装备。

# 三、干员三支柱 ★

## 3.1 盟约搭配
- 1 核心 + 1~2 附加，都凑满 3 人
- 例：莱塔尼亚（折光是经济引擎，每回合 +4 层）+ 奥术（法伤）

## 3.2 干员搭配
- 阵型：**盾 → 战士 → 输出 → 奶**（敌人来的方向 ← 自己蓝门）
- d 行排法：`d7 盾 → d6 战士 → d5/d4 输出 → d3 奶`
- 同名凑 3 个 → **精锐**（属性跃升最大来源）

## 3.3 装备搭配
- 商店 **x=520** 那格卖装备（随身身份牌 / 坚守盾牌 / 聚合急救箱 / 精准狙击镜 / 乌萨斯呼吸器…）
- 买到后放在**装备区**：**y≈552，5 格，x≈542 / 667 / 792 / 917 / 1042**
- **必须拖到干员身上才生效**（和放干员一样）
- 分配：前排装防御/阻挡+1，狙击装增伤，输出装攻速

# 四、布阵（最容易出错的一章）

## 4.1 地块（本图 AC-SP-2）

**地面 13 个（能阻挡）**
```
a2 a3 a7 a8 / b3 b7 / c3 c7 / d3 d4 d5 d6 d7
```
**围墙 6 个（能放但不阻挡）**
```
b2 b6 c2 c5 c6 d2
```

## 4.2 第 7 列不能放远程 ★

第 7 列（d7/c7/b7/a7）是**下路敌人爬升 + 上路敌人横穿的第一接触点**，
远程放那儿会先挨打。

**远程放第 5、6 列**（c5/c6、b6 一带），靠 7 列的前排挡着。

## 4.3 朝向：指向「友军阻挡的那一格」★

| 干员位置 | 敌人被挡在哪 | 朝向 |
|---|---|---|
| d4（左端） | d5~d7（右边） | **right** |
| d7（最右） | 自己在挡 | right 或 down |
| c5/c6（后排） | d5~d7（上方） | **up** |

**不是全场统一方向，也不是"朝敌人来的方向"。**

## 4.4 近战也可能是远程模板 ★

像**烈夏**这类「近战位 + 远程攻击模板」的干员，朝下只能打脚下空地，
必须朝 right（顺 d 行）才够得到前排。

**放之前查一下这个干员的攻击模板。**

## 4.5 挡住 ≠ 打死 ★

至少 **2 个输出的攻击范围要覆盖同一个阻挡点**。
只有 1 个能打到 = 怪被卡着不掉血，耗到突破。

## 4.6 远程打重甲效率低
持盾者 / 重装侦察兵 / 粉碎攻坚组长 → **上术师（法伤）**，物理狙击几乎打不动。

## 4.7 没有近战位时，远程要顶上挡
但要挑**攻击范围覆盖最长路径**的格子（本图 d5~d7）。

# 五、操作（按钮坐标，实测）

| 操作 | 做法 |
|---|---|
| **放干员** | 按住卡片从中心偏左拖到格子 → 划朝向 **400px / 1200ms** → 点格子核对名字 |
| **放装备** | 从装备格（y≈552）拖到干员格 **1600ms** → 长按干员验证 |
| **撤退**（可重放） | 长按干员 → 点 **(542,389)**（图标按钮，无文字） |
| **出售**（卖钱，人没了） | 长按干员 → 点 **(732,338)** |
| 关面板 | 点棋盘空白处（1150,400） |
| 收起/展开商店 | 右下 (1191,674) |

## 铁律

1. **放人前必须收起商店**（展开时盖住棋盘，落点全错）
2. **改朝向/改位置用「撤退」，不要用「出售」**（我今天点错把烈夏卖了）
3. **❌ 绝不按返回键**（keyevent 4 会直接退出游戏）
4. **放完必须点格子核对名字**
5. 名额（剩余可放置）：撤退/出售场上干员会释放，干员阵亡也会释放

# 七、地图结构

```
d 行：d1 ... d7 d8 [d9 红门]    ← 上红门
c 行：       c3       c7
b 行：       b3       b7
a 行：[蓝门] a1 ... a7 a8 [a9 红门]   ← 下红门
```

- **两个红门都会出兵**
- **下路斜着走**：a8→a7 / b8→b7→c7 / c8→c7，**最后都汇到 d 行**
- **d 行是汇合点**，最该重兵把守
